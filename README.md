Unity classroom project for console-game development.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/SampleScene.unity](https://github.com/kleberandrade/aula-console-unity/blob/main/Assets/Scenes/SampleScene.unity).

## Recorded requirements

- Recorded Unity Editor: **2020.2.1f1** in [ProjectSettings/ProjectVersion.txt](https://github.com/kleberandrade/aula-console-unity/blob/main/ProjectSettings/ProjectVersion.txt).
